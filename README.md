# Dollar Exchange API Viewer

Aplicación de escritorio desarrollada en Python y Tkinter para consultar y visualizar la cotización del dólar en Argentina mediante una API.

## Uso

1. Clonar el repositorio:

```bash
git clone https://github.com/Markchat21/dollar-exchange-api-viewer.git
cd dollar-exchange-api-viewer
```

2. Instalar las dependencias:

```bash
pip install -r requirements.txt
```

3. Ejecutar la aplicación:

```bash
python3 main.py
```

## Tecnologías

* Python
* Tkinter
* API REST
